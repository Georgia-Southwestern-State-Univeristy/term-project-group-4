# User Guide
## Smart Packing Checklist Generator

This guide explains how to use the Smart Packing Checklist Generator as an end user.

---

## Who This Is For

This application is designed for:

- Travelers who want help packing for trips
- Users who want to organize and track packing lists
- Anyone who prefers a simple, structured checklist instead of manually planning

---

## What You Can Do

Users can:

- Log in using Google
- Create a trip
- Generate a packing checklist based on trip details
- Save trips for later
- Load and edit existing trips
- Track packing progress by checking items
- Search and filter saved trips
- Delete trips

---

## Getting Started

### Accessing the Application

The live application is available at:

https://spcg.zentrofi.com

No installation is required. Simply open the link and log in with Google.

### Log In

- Open the application in your browser
- Click the **Login with Google** button
- Complete the Google authentication flow

Once logged in, the main application will be visible.

---

## Core Workflows

### Create and Save a Trip

1. Enter trip details:
   - Trip Name
   - Destination Type (e.g., beach, camping)
   - Duration (number of days)

2. Click **Generate Checklist**
3. Review the generated checklist
4. Click **Save Trip**

You will see a confirmation message when the trip is saved.

### Load and Edit a Trip

1. Locate your trip in the **Saved Trips** list
2. Click **Load**
3. The form will populate with saved values
4. The app will show:
   `Editing: <trip name>`

5. Make changes:
   - Update trip details
   - Modify checklist items

6. Click **Update Trip** to save changes

> Note: The **Update Trip** button is only enabled after you make changes.

### Track Packing Progress

- Check or uncheck items in the checklist
- Changes are automatically saved for existing trips

> Auto-save happens silently (no notification spam)


### Search for a Trip

- Use the search bar above the saved trips list
- Type part of the trip name
- The list will filter in real time

### Delete a Trip

1. Find the trip in the saved list
2. Click **Delete**
3. Confirm the deletion

This action cannot be undone.

---

## Known Limitations

- Checklist generation is rule-based and may not cover all edge cases
- Changes to checklist items are auto-saved but not versioned
- The app requires login to access any functionality
- No offline support (requires internet connection)
- No sharing or collaboration features

---

## Tips for Best Use

- Use clear, descriptive trip names for easier searching
- Always click **Update Trip** after editing trip details
- Use checklist tracking instead of rewriting lists manually

---

## Error Handling

- If login fails, an error message will appear
- If something goes wrong, retry the action or refresh the page
- Most errors will display as a notification at the top of the screen

---

## Summary

The application is designed to be simple and fast:

- Create → Generate → Save → Track → Update

No advanced setup is required for normal use.
